# Lucky Buck Ticket 1.0.0 — art restore (November 8, 2026)

Owner approved this version after trying the preview ("this is the new best model", then "Yes" to making it live).

Files changed: `ticket-1.0.0.html` and `playtest.html` (identical). `index.html` (calculator, v3.3.3) is unchanged.

## What changed
- **Front:** the original artwork image is back, untouched. The runtime "polish" code that recolored the sky and cut out the logo was removed.
- **Flip badge:** a mirror copy of the original $1 badge (same shape, color and stepped corners) with a hand-drawn pixel arrow, placed in the top-right corner. The flip button itself is now an invisible tap target over the badge.
- **Back:** shows the same original image as the front, so the frame and logo are identical pixels. Below the logo is a cream printed panel with:
  - "$1 MATCH 3 AMOUNTS TO WIN!" heading (Lilita One, deep purple)
  - numbered rules 1 SHOOT / 2 REVEAL / 3 WIN (Lilita One headings, Roboto Condensed Bold text — closest free match to the Hoosier Lottery reference, not the exact font)
  - Buck's Secret in red handwriting (Annie Use Your Telescope), exact approved wording
- All text sizes scale with the ticket, so the layout is the same at every phone width.

## Owner decisions during this work
- Keep the original logo and front art (the earlier sky/logo edits looked over-edited).
- Buck's Secret ink: red.
- Rules lettering: big, fun, readable.

## Not changed
Odds, shooting, aim wobble, balloons, hit detection, sounds, testing controls, calculator.

## Tests
- Browser emulation at 320 and 430 px wide (layout scales, so 375/390/402 match): all back text inside the panel.
- Played a forced $5 winner and a forced loser; flipped to the back and returned; no page errors.
- Checked the back panel never covers the outer frame or logo area (0 pixels).
- **Not yet tested on a real iPhone.**

## Known limits
- On the front, the flip badge covers the tips of the right antler, because the original logo sits slightly right of center.
- Fonts load from Google Fonts; offline, the browser falls back to similar system fonts.
