Files changed: `index.html` (calculator, v3.3.3 → **v3.4.0**), `ticket-1.0.0.html` and `playtest.html` (identical).
Rollback branch: `backup/before-skill-mode-2026-11-08` (commit 6fce0c9).
Build tools: `design/skill-mode-tools/` (see the README there).

## What changed

### Calculator
- **Skill mode switch** at the top.
  - **OFF:** the ticket uses the calculator's prize odds and Luck level.
  - **ON:** where you hit each balloon decides its number.
- **In Skill mode:**
  - The Special Function box (shot accuracy / Rescue Bonus) and the small scratch ticket are hidden.
  - The odds and modifier boxes are dimmed, with a note that the ticket ignores them.
  - **The real game ticket appears big at the top**, playable in the calculator, with an "Open full screen" link.
  - **Play settings** sit under the ticket: balloon speed (1.6×), movement distance (100%), **balloon size (new, 70–130%, default 100%)**, crosshair pattern size (20px), crosshair height above finger (130px), sound, and a reset button.
- **Balloon target zones box** (Skill mode):
  - One 37×45 pixel grid (the balloon's real pixels) applies to all three balloons.
  - Paint gold / green / yellow / red with brushes of 1, 3×3 or 5×5 squares, zoom up to 3×, and use Move to scroll while zoomed.
  - Each colour's prize is editable.
  - Quick rings repaint by size.
  - A zone table and a random-hit estimate are shown.
  - Adjustable **shells per ticket**.
- **Buck's Secret box** (both modes): on/off, extra per gold hit, most extra per ticket.

### Ticket
- Reads the calculator's settings automatically (same website, same saved data). Changes apply on the next ticket; play-setting changes apply immediately.
- **The grid is never shown to the player.** Balloons look exactly as before.
- **Skill ON rules:**
  - Hit pixel colour → balloon number: gold $25, green $5, yellow $1, red $0.
  - **Your worst shot sets the prize** (5, 5, 1 pays $1; any $0 means no prize).
  - **5 shells per ticket.** Every shot uses one; balloons left when you run out count as $0.
  - A gold hit is **Buck's Secret** and shows $25.
- **Skill OFF rules:**
  - Odds come from the calculator's lucky-buck ticket (prize rows plus Luck level, including custom Luck rates). Built-in 75/17/6.5/1.5 is used if there is no save.
  - Unlimited misses, as before.
  - A gold hit pays the Buck's Secret extra (+$1 each, up to +$2 per ticket), even on a losing ticket.
- Testing controls gained a balloon size slider and stay in sync with the calculator.

## Defaults
- Gold = only the dead-centre pixel (1 square). Green ring to 6.5 px, yellow to 11.5 px, the rest red.
- Values: gold $25, green $5, yellow $1, red $0.
- Shells: 5.
- Buck's Secret: on, +$1 per gold hit (Skill OFF), max +$2 per ticket.
- Skill mode starts **OFF**.

## Not changed / known limits
- Ticket art, balloons, crosshair, aiming patterns and prize-number look are unchanged.
- Rescue Bonus, Hot Streak, Double Down and special items are still **not** applied on the ticket.
- The calculator's batch simulator ("Run multiple tickets") does not simulate Skill mode yet.
- Skill-mode payouts are a first foundation, not balanced. The random-hit estimate is about a 12% win rate and $0.14 back per $1. A planned shot tracker would measure real aim to tune prizes.
- Skill settings are saved in this browser (`lucky-buck-skill-v1`), like the rest of the calculator.

## Tests (browser, iPhone-sized 375 px)
- Painting saves.
- Ring scoring is exact at 100% and 120% balloon size (3 px off-centre = green, centre = gold, past the edge = miss).
- Worst-shot rule: 5,5,1 → $1; 25,25,25 → $25; 5,1,0 → loss.
- Shells: 2 hits + 3 misses ends the ticket with a $0 balloon; 5 misses → all $0.
- Skill OFF follows calculator odds (Luck 3 → 64/20/12.5/3.5); forced loser with centre hits paid Buck's Secret $2.
- Sliders in the calculator change the embedded ticket.
- Turning Skill off restores the normal calculator.
- No page errors.
