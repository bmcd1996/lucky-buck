## User-approved gameplay design
- Implement a rescue bonus mechanic in the **existing** Lucky Buck simulator UI, not the earlier standalone calculator prototype, preserving artwork, logo, ticket layouts, statistics and bought ticket queues.
- Base default odds for $1 Lucky Buck: **Lose 75%, $1 17%, $5 6.5%, $25 1.5%**. Base win probability 25%, base cash expected payout $0.87 per $1 ticket before a one-in-600 special-item ticket replaces a cash draw.
- Every scratch first receives its cash prize or loss from normal prize odds (including normal Luck and Momentum modifiers when equipped). A successful bullseye can rescue an underlying losing ticket to $1. A missed or partial shot never decreases the original prize.
- Rescue chance dropdowns: first bullseye, second **consecutive** bullseye, third **consecutive** bullseye. A failed rescue chance can be retried at the next consecutive bullseye. An interruption resets streak. Any bullseye can start a new streak.
- Three consecutive bullseyes also unlock a separate **prize upgrade** chance: $1→$5, $5→$25; $25 is unchanged. It is possible to rescue a loser then upgrade it on a triple.
- Bullseye threshold in Default is 95–100%. No bonuses or modifier levels are turned on by default: all three rescue dropdowns and triple-upgrade chance start at **0%**, all three equipment modifiers at level 0. The previous preview configuration **17%, 50%, 100%, 28%** is an *experimental combination*, NOT the Default preset.
- Batch runs: the new “Apply selected shooting bonuses” checkbox is unchecked by default; unchecked means ordinary **auto-scratch**, skipping rescue and upgrade effects. Checking it uses the current shot accuracy. Existing random-accuracy option can additionally turn on shooting for batches.
- The special Trusty Shotgun item remains separate with 1 per 600 in pack mode.
- Previous saved Default/Shooter Bonus/Custom slot values are reset once and backed up in browser storage under `lucky-buck-presets-before-rescue-v3-3`. Custom 1's label is restored from Shooter Bonus to Custom 1. Existing ticket save is backed up under `quill-lucky-buck-v2-pre-rescue-v3-3` before converting old shot bonuses to zero-based Rescue settings. Other saved history, purchased tickets and artwork are not wiped. Active ticket prize rows and equipped modifiers are deliberately not automatically overwritten: use **Saved Preset → Default → Load selected** to apply new baseline to the currently selected ticket.
- Default factory preset is always available, custom slots are empty after reset.
